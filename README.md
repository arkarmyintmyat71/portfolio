# Portfolio

Arkar Myint Myat's portfolio. Plain HTML, CSS and JavaScript, no build step.

- `index.html` – all content
- `assets/css/style.css` – styles (colour and type tokens at the top)
- `assets/js/script.js` – header state, active nav link, contact form (Web3Forms)
- `assets/img/` – portrait and project screenshots

To publish, push to the repo that serves GitHub Pages.
