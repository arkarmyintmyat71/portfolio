Gemini AI Chatbot

A chat app that answers questions using Google's Gemini AI. Replies appear word by word as they arrive, like typing.

  • Streams each reply live instead of waiting for the full answer
  • Remembers the last 10 messages, so follow-up questions make sense
  • Tries a backup model automatically when the first one is busy
  • Auto-scrolls to new messages, shows timestamps and can clear the chat
BrowserReact 19, custom hooks, Vite
